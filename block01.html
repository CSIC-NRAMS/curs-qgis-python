Bloc 01 — Meteocat: neteja i estandardització

Introducció del bloc

En aquest bloc transformarem el CSV de Meteocat en un format net i consistent: seleccionarem columnes, netejarem números, filtrarem coordenades i normalitzarem dates.

Aquest procés ens dona un fitxer final estàndard que després podrem combinar amb AEMET.

Prerequisits: Bloc 00 completat (config i tools creats) i CSV Meteocat a dades/entrada/.

Resultat esperat: fitxer meteocat_std.csv a resultats/ i missatges “OK” a la consola.

ex02_select_columns.py

📥 Descarregar Script
Fase: Filtratge de columnes
import os
import sys

ROOT_DIR = os.path.dirname(os.path.dirname(__file__))
if ROOT_DIR not in sys.path:
    sys.path.append(ROOT_DIR)

from tools.config import METEOCAT_INPUT, PAS1_OUT, RESULTATS_DIR
from tools.csv_utils import ensure_dir, open_csv_reader, open_csv_writer, preview_csv

ensure_dir(RESULTATS_DIR)
columnes = ["EMA", "DATA", "X", "Y", "PPT"]
files = 0

with open_csv_reader(METEOCAT_INPUT) as lector, \
     open_csv_writer(PAS1_OUT, fieldnames=columnes) as escriptor:

    for fila in lector:
        nova_fila = {col: fila.get(col, "") for col in columnes}
        escriptor.writerow(nova_fila)
        files += 1

preview_csv(PAS1_OUT, max_rows=5, title="Preview meteocat_pas1.csv")
print(f"OK -> creat {PAS1_OUT}")
print(f"Files processades: {files}")

🔍 Anàlisi Tècnica

Aquí creem un nou CSV quedant-nos només amb les columnes importants (EMA, DATA, X, Y, PPT). Ho fem per simplificar els següents passos: com menys soroll, més fàcil és detectar errors i entendre què està passant.

Per què crear un fitxer nou? Treballar per fases ens permet tornar enrere si alguna cosa surt malament i comparar el resultat pas a pas.

Utilitzem una dictionary comprehension per crear un nou diccionari només amb les claus que ens interessen, descartant la resta d'informació.

ex03_clean_numbers.py

📥 Descarregar Script
Fase: Neteja de tipus de dades
import os
import sys

ROOT_DIR = os.path.dirname(os.path.dirname(__file__))
if ROOT_DIR not in sys.path:
    sys.path.append(ROOT_DIR)

from tools.config import PAS1_OUT, PAS2A_OUT, RESULTATS_DIR
from tools.csv_utils import ensure_dir, open_csv_reader, open_csv_writer, preview_csv
from tools.parse_utils import to_float

columnes = ["EMA", "DATA", "X", "Y", "PPT"]
files_llegides = 0
files_escrites = 0

ensure_dir(RESULTATS_DIR)

with open_csv_reader(PAS1_OUT, encoding="utf-8") as lector, \
     open_csv_writer(PAS2A_OUT, fieldnames=columnes) as escriptor:

    for fila in lector:
        files_llegides += 1
        x = to_float(fila.get("X"))
        y = to_float(fila.get("Y"))
        ppt = to_float(fila.get("PPT"))

        nova_fila = {
            "EMA": fila.get("EMA", ""),
            "DATA": fila.get("DATA", ""),
            "X": x,
            "Y": y,
            "PPT": ppt
        }
        escriptor.writerow(nova_fila)
        files_escrites += 1

preview_csv(PAS2A_OUT, max_rows=5, title="Preview meteocat_pas2a.csv")
print(f"OK -> creat {PAS2A_OUT}")

🔍 Anàlisi Tècnica

Pas important: aquí convertim X/Y/PPT a número (float), però encara no descartem files. Separem “convertir” de “validar” perquè el procés sigui més fàcil d’entendre i depurar.

Imports i funcions: usem to_float perquè molts números venen com a text (i amb coma). Convertir-ho a float és imprescindible per fer càlculs després.

Idea clau: si una coordenada o un valor no es pot convertir, no parem el programa: el marquem com a buit o el descartem segons el criteri de l’exercici.

Convertim strings a floats. Això és crucial perquè "10,5" no es pot operar matemàticament, però 10.5 sí. La funció to_float s'encarrega de reemplaçar la coma per punt.

ex04_filter_coords.py

📥 Descarregar Script
Fase: Control de qualitat espacial
import os
import sys

ROOT_DIR = os.path.dirname(os.path.dirname(__file__))
if ROOT_DIR not in sys.path:
    sys.path.append(ROOT_DIR)

from tools.config import PAS2A_OUT, PAS2B_OUT, RESULTATS_DIR
from tools.csv_utils import ensure_dir, open_csv_reader, open_csv_writer, preview_csv

columnes = ["EMA", "DATA", "X", "Y", "PPT"]
files_llegides = 0
files_escrites = 0
files_saltades = 0

ensure_dir(RESULTATS_DIR)

with open_csv_reader(PAS2A_OUT, encoding="utf-8") as lector, \
     open_csv_writer(PAS2B_OUT, fieldnames=columnes) as escriptor:

    for fila in lector:
        files_llegides += 1
        x = fila.get("X")
        y = fila.get("Y")

            files_saltades += 1
            continue

        escriptor.writerow(fila)
        files_escrites += 1

preview_csv(PAS2B_OUT, max_rows=5, title="Preview meteocat_pas2b.csv")
print(f"Files saltades (X o Y buits): {files_saltades}")

🔍 Anàlisi Tècnica

Per què aquest pas existeix? Un punt sense X o Y no es pot mapar. Per això descartem files amb coordenades buides abans d’intentar transformacions CRS.

Control de qualitat: un punt sense X o Y no es pot dibuixar en un mapa. Per això “saltem” aquestes files amb continue.

Per què fer-ho ara? si filtrem aviat, evitem errors quan fem la transformació de CRS (que necessita coordenades vàlides).

Eliminem registres que no es podrien dibuixar en un mapa. Si x o y són None (fruit de la neteja anterior) o buits, saltem la iteració amb continue.

ex05_normalize_dates.py

📥 Descarregar Script
Fase: Estandardització temporal
import os
import sys

ROOT_DIR = os.path.dirname(os.path.dirname(__file__))
if ROOT_DIR not in sys.path:
    sys.path.append(ROOT_DIR)

from tools.config import PAS2B_OUT, PAS3_OUT, RESULTATS_DIR
from tools.csv_utils import ensure_dir, open_csv_reader, open_csv_writer, preview_csv
from tools.parse_utils import parse_date

columnes = ["EMA", "DATA", "X", "Y", "PPT"]
files_llegides = 0
files_escrites = 0
files_saltades = 0

ensure_dir(RESULTATS_DIR)

with open_csv_reader(PAS2B_OUT, encoding="utf-8") as lector, \
     open_csv_writer(PAS3_OUT, fieldnames=columnes) as escriptor:

    for fila in lector:
        files_llegides += 1
        data = parse_date(fila.get("DATA"))

        if data is None:
            files_saltades += 1
            continue

        nova_fila = dict(fila)
        nova_fila["DATA"] = data.isoformat()
        escriptor.writerow(nova_fila)
        files_escrites += 1

preview_csv(PAS3_OUT, max_rows=5, title="Preview meteocat_pas3.csv")
print(f"Files saltades (data invàlida): {files_saltades}")

🔍 Anàlisi Tècnica

Què estandarditzem? Convertim la data a format ISO (YYYY-MM-DD). Això fa que ordenar i unir sèries temporals sigui consistent entre fonts.

Objectiu: convertir totes les dates al mateix format (YYYY-MM-DD). Això permet ordenar, filtrar i unir dades de fonts diferents sense confusions.

Per què ISO? perquè és un estàndard internacional i, a més, ordena bé alfabèticament (text) i cronològicament (temps).

Convertim qualsevol format de data d'entrada (DD/MM/YYYY) a l'estàndard ISO 8601 (YYYY-MM-DD). Això permet ordenar cronològicament les dades com a text simple.

ex06_transform_crs.py

📥 Descarregar Script
Fase: Reprojecció Geogràfica
import os
import sys

ROOT_DIR = os.path.dirname(os.path.dirname(__file__))
if ROOT_DIR not in sys.path:
    sys.path.append(ROOT_DIR)

from tools.config import PAS3_OUT, PAS4_OUT, RESULTATS_DIR
from tools.csv_utils import ensure_dir, open_csv_reader, open_csv_writer, preview_csv
from tools.qgis_utils import get_utm31_to_wgs84_transformer, transform_utm_to_lonlat

columnes = ["EMA", "DATA", "X", "Y", "PPT", "lon", "lat"]
xform = get_utm31_to_wgs84_transformer()
files_llegides = 0
files_escrites = 0
files_saltades = 0

ensure_dir(RESULTATS_DIR)

with open_csv_reader(PAS3_OUT, encoding="utf-8") as lector, \
     open_csv_writer(PAS4_OUT, fieldnames=columnes) as escriptor:

    for fila in lector:
        files_llegides += 1
        try:
            x = float(fila.get("X"))
            y = float(fila.get("Y"))
        except:
            files_saltades += 1
            continue

        try:
            lon, lat = transform_utm_to_lonlat(x, y, xform)
        except:
            files_saltades += 1
            continue

        nova_fila = dict(fila)
        nova_fila["lon"] = lon
        nova_fila["lat"] = lat
        escriptor.writerow(nova_fila)
        files_escrites += 1

preview_csv(PAS4_OUT, max_rows=5, title="Preview meteocat_pas4.csv")
print(f"OK -> creat {PAS4_OUT}")

🔍 Anàlisi Tècnica

Entrant al SIG: ara sí, fem la reprojecció amb PyQGIS i afegim lon i lat. Aquestes dues columnes permeten carregar el CSV com a punts a QGIS.

Imports PyQGIS: utilitzem QGIS per transformar coordenades d’UTM (metres) a WGS84 (graus). Això ens dona lon i lat per poder carregar el CSV com a punts.

Pas clau: la transformació només té sentit si X i Y són números vàlids. Per això hem netejat i filtrat abans.

Afegim les columnes lon i lat. Utilitzem un bloc try/except per assegurar que si una coordinada concreta és corrupta, no aturi tot el procés.

ex07_standardize.py

📥 Descarregar Script
Fase: Mapeig final de camps
import os
import sys

ROOT_DIR = os.path.dirname(os.path.dirname(__file__))
if ROOT_DIR not in sys.path:
    sys.path.append(ROOT_DIR)

from tools.config import PAS4_OUT, STD_OUT, STD_FIELDS, RESULTATS_DIR
from tools.csv_utils import ensure_dir, open_csv_reader, open_csv_writer, preview_csv

files_llegides = 0
files_escrites = 0
files_saltades = 0

ensure_dir(RESULTATS_DIR)

with open_csv_reader(PAS4_OUT, encoding="utf-8") as lector, \
     open_csv_writer(STD_OUT, fieldnames=STD_FIELDS) as escriptor:

    for fila in lector:
        files_llegides += 1

        ema = (fila.get("EMA") or "").strip()
        data = (fila.get("DATA") or "").strip()
        ppt = fila.get("PPT")
        lon = fila.get("lon")
        lat = fila.get("lat")
        x_utm = fila.get("X")
        y_utm = fila.get("Y")

        if not (ema and data and lon and lat and x_utm and y_utm):
            files_saltades += 1
            continue

        nova_fila = {
            "source": "METEOCAT",
            "station_id": ema,
            "station_name": f"Olot (Meteocat EMA {ema})",
            "date": data,
            "precip_mm": ppt,
            "lon": lon,
            "lat": lat,
            "x_utm": x_utm,
            "y_utm": y_utm,
            "alt_m": ""
        }
        escriptor.writerow(nova_fila)
        files_escrites += 1

preview_csv(STD_OUT, max_rows=5, title="Preview meteocat_std.csv")
print(f"OK -> creat {STD_OUT}")

🔍 Anàlisi Tècnica

Què vol dir “estandarditzar” aquí? Crear un fitxer final amb les mateixes columnes i el mateix significat, independentment de la font. Això és el que farà possible el “merge” final.

Mapeig de camps: aquí reanomenem i reordenem camps (ex: EMA → station_id) i fixem source a “METEOCAT”.

Creem el fitxer final amb l'estructura definitiva (source, station_id, etc.). Aquí "hardcodegem" el valor de source a "METEOCAT".
